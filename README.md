# Velox Shield 🛡️


Velox Shield is a lightweight Chrome extension designed to automatically detect and reject annoying cookie banners, ensuring a cleaner and faster browsing experience.

## 🚀 Features
* Auto-Rejection: Automatically clicks "Reject", "Decline", or "No" on cookie pop-ups.
* Deep Scan (Force Mode): A powerful manual tool to remove stubborn banners that hide page content.
* Scroll Recovery: Automatically restores page scrolling if a banner has locked it.
* Multi-language Support: Works on both international and Georgian websites.

## 🛠️ How to Install (Manual Mode)
Since we are in development, follow these steps to install:
1. Click the green Code button above and select Download ZIP.
2. Extract the ZIP file to a folder on your computer.
3. Open Google Chrome and navigate to chrome://extensions/.
4. Turn on Developer mode (top right switch).
5. Click Load unpacked and select the folder where you extracted the files.
